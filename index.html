Para quem é · Para quem NÃO é

✓ É para você se...

  • ✓Você é analista, coordenador, gerente, especialista — quer ser a pessoa de IA da sua área.
  • ✓Quer evidência (dados IBM, casos reais), não promessa de R$10k/mês.
  • ✓Prefere ser puxado pra cima dentro da empresa OU prestar serviço pra 3-5 clientes — sem hustle de cold call.
  • ✓Quer um caminho adulto, profissional, com framework — não hype.

✗ NÃO é para você se...

  • ✗Você procura "segredos" para virar AI agency em 90 dias.
  • ✗Quer virar prompt engineer puro — este curso é sobre profissão + IA, não sobre prompt-craft.
  • ✗Acredita que IA é só "mais uma camada tecnológica" — aqui tratamos como novo modelo operacional.
  • ✗Não está disposto a documentar wins e construir reputação composta em 12 semanas.
