⚙️ Automação No-code / Low-code

n8n, Make, Zapier, Power Automate + agentes. Você não precisa programar — precisa orquestrar.

1

🛠️ Os 4 ecossistemas no-code

Cada ferramenta tem mandato. Saber qual indicar a qual cliente é skill consultiva.

Comparação rápida

  • • n8n — open-source, self-host, mais técnico, sem limite de operação. Pra quem aceita complexidade.
  • • Make — visual, robusto, bom equilíbrio. Custa USD 9-30/mês. Pra PME.
  • • Zapier — fácil, caro, foco USA. USD 20-100/mês. Quando velocidade vence custo.
  • • Power Automate — Microsoft. Melhor pra enterprise que já é Microsoft-heavy.
2

🔄 5 padrões universais de fluxo

80% dos casos cabem em 5 padrões. Repertório = capacidade de propor solução em 5 minutos numa reunião.

  • 1. Email → IA → CRM — categoriza, atualiza pipeline, cria task
  • 2. Reunião → IA → Síntese + email — transcrição, resumo, follow-up
  • 3. Form → IA → Slack/Teams — qualificação automática + notificação humana
  • 4. Upload PDF → IA → Resumo + Notion — leitura assistida em escala
  • 5. Schedule diário → IA → Relatório — KPIs sintetizados todo dia
3

🚨 Tratamento de erro

Maioria dos fluxos quebra por: null não tratado, API rate limit, timeout, JSON inválido. Robustez é skill que cliente paga prêmio.

Patches padrão

  • • Null handling: default values + branch IF para vazio
  • • Retry: 3 tentativas com backoff exponencial
  • • Idempotência: usar ID único pra evitar duplicação em retry
  • • Logging: toda execução em LangSmith/Helicone/planilha
  • • Alert: Slack/email quando falha >3 vezes seguidas
4

💰 Custo total de fluxo

Plataforma + API LLM + storage. Sem cálculo, proposta vira "depende".

Cálculo de exemplo

  • • Plataforma (Make): R$ 80/mês
  • • Claude Sonnet API: R$ 0,03 por execução (1k input + 500 output tokens)
  • • 1.000 execuções/mês = R$ 30 API + R$ 80 plataforma = R$ 110/mês total
  • • Comparado a R$ 5k de salário/mês economizado = ROI 45x
  • • CFO/cliente compra em 1 reunião
5

🤖 Quando incluir agente

2026 todo mundo quer agente. Saber quando NÃO indicar é a skill premium.

Use agente

  • • Caminho varia por contexto
  • • Decisão é contextual
  • • Múltiplas ferramentas usadas
  • • Loop natural (descobrir + agir + verificar)

Use fluxo determinístico

  • • Sequência fixa, sem ramificação
  • • Validação simples (regex, range)
  • • Custo é crítico (agente roda 3-10x mais tokens)
  • • Auditabilidade exigida (regulação)
6

📈 Observability

Log de execução + métrica de sucesso + alerta. Sem isso, você não sabe se modelo regrediu. Profissional sênior monta observability desde o piloto.

Stack de observability comum

  • • LangSmith (LangChain) — trace de execução, eval set
  • • Helicone — proxy + log + custo por usuário
  • • Langfuse — open-source alternativo
  • • Métricas-chave: latência (p95), token usage, taxa de erro, custo/exec
